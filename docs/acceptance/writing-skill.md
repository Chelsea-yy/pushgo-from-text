# 策划案转活动文稿 Skill：阶段验收

## 交付范围

新增 `skills/campus-push-writer/`，用于当前 Agent 读取策划材料、学习参考文稿模块、选择读者主线、写作、审稿与修订。不是模型微调，也不宣称保证阅读或转发。当前重点为活动预告；回顾只沉淀阶段差异，缺少真实会后记录时不能由策划案生成回顾事实。

公开交付包括主 Skill、模块内容与选材、评审规约、独立虚构示例、可移植写作指令和指标证据模板。真实源文件、全文、身份与链接映射、试写和逐项审稿仅在已忽略的本地目录中保存。

入口：

- 明确要求当前 Agent 读取 `skills/campus-push-writer/SKILL.md` 即可使用，无需另外设置模型 API。
- `AGENTS.md` 提供写作与排版入口指引，但本轮未独立验收它的自动加载。
- `npm run skill:install` 只复制公开 Markdown 到 `.cursor/skills/campus-push-writer/`，已存在则拒绝覆盖，不安装后台服务或改用户级设置。
- 本轮访问 Cursor 官方 Skills/Rules 文档未成功，未验证此客户端的原生发现、斜杠调用、重载要求。复制验收不等于自动加载验收，当前使用路径为显式读取源文件。

## 参考研究

实际研究9篇可读正文：5篇预告、4篇回顾。逐篇拆解标题、导语、读者用途、基础信息、亮点、人物/企业/项目、议程、行动和组织署名；比较不同模块的任务和选择顺序，而不是套统一模板。

完整匿名结论见 [写作模式研究](../research/writing-patterns.md)。新增样例部分只保留标明的摘录，不冒充完整网页存档；图片文字、二维码目的地、移动端视觉不在本轮核实范围。

九篇的阅读、分享/转发、点赞及其他互动数字均未知，没有热度排名或高传播因果证据。操作按钮不等于次数，参会人数和议程时刻不算阅读或分享数据。后续可接收有权提供的打码后台截图或匿名汇总，再按指标模板追加比较；当前结构学习结论不因此变成传播验证。

## 五例迭代与停止条件

五份真实本地材料完成首稿、未执笔者审稿、主控定向修订。首稿和审核均保留，非盲测；量表是主观内部编辑标准。源材料中三份为策划PDF，两份已接近推送文字稿，后两例主要检验重组/压缩，不能据此证明通用转换能力。

| 匿名案例 | 首稿 → 最终内部编辑分 | 实际问题与修订 |
| --- | --- | --- |
| S01 | 82 → 85/100 | 合并重复问答与环节描述，修正职业类别的拗口表达，前置时间 |
| S02 | 85 → 87/100 | 投融资内容前移形成两条连贯主线；终审抽查发现一处相邻问句与参考近似，再局部改为独立陈述结构至v3 |
| S03 | 81 → 84/100 | 删除尾部重复总括，简化举办句；恢复源稿明确的地点通知口径，不因二维码缺失删除所有有效信息 |
| S04 | 80 → 82/100 | 压缩泛化说明；删除未完成版面确认的精确子议程及断裂问句，不靠猜测补项目卡片 |
| S05 | 82 → 87/100 | 首稿虽达参考线仍返工：删除材料审查口吻和免责句，简化未释义缩写，前置时间并减少重复邀请 |

总分不能覆盖具体缺陷。S05即使达到参考线，仍因洁稿中混入审核语言而返工。缺真实入口的7分资产项没有通过编二维码、免费或余量来补分。

最终独立复核：S01/S03/S04/S05止于v2，S02止于v3，已读历史文本范围内没有待修复关键写作问题，可交用户审阅。主控复读实际成稿、源文和终审结果，核对修改确实发生；模仿边界仅为指定留存文本抽查，不是全库查重或法律原创性保证。S02的v2发现与未通过记录另档保留，没有倒改旧版结论。

停止依据是具体问题修复、文本硬检查通过且达到参考线，不是凭总分放过缺陷或为了版本上限强行通过。后续若要求补充S04项目细节或恢复分钟议程，需要新证据，不宜无依据继续润色。

每例交付四份：`article.md`（标题和正文）、`title-options.md`、`editor-review.md`、`revision-log.md`。入口索引为本地 `.local/writing-practice/README.md`，修订稿在其 `final/S01` 至 `final/S05`。

## 历史与事实边界

全部活动日期在本轮日期2026-10-20之前，均为历史预告体练习，不可当作当前报名文稿发布，年份未自动改动。正文洁稿与历史标记、出处及阻塞分开交付。

- 拟邀与拟设状态保留，不从已发布成稿或回顾反推确认。
- 详细内部地址、组织角色冲突、未核验二维码、精细表格读序仍分别记录。
- S04删去不充分支持的细节，不能据此宣称原版面已核实；恢复项目或分钟议程须先补证据。
- S03与S05源文件已是较完整文稿，不视作复杂策划书转换的独立盲测。
- 传播指标未知、用户主观认可尚未取得、没有真实发布实验；编辑检查与这些验收分开。

## 工程检查

- `npm run check`：类型检查、48项测试、构建全部通过；其中5项为新增写作 Skill 的结构、安装及边界回归检查。
- `npm run skill:install`：已在本机实际运行，候选目录副本就位；未验收自动发现。
- 对15个本轮公开改动文件完成已知私有标识、原始文件名、参考原题/URL及常见密钥模式扫描，命中0；此检查不等于完整匿名性证明。
- 新增测试核对主文件字段与引用、安装内容与源包一致、拒绝覆盖本地修改、拒绝非目录/链接父路径、关键边界说明。
- `node scripts/check_writing_practice.mjs`：实际通过，5份原文件SHA-256与提取前后记录相同，20份交付文件和5对独立审稿存在，9篇指标记录完整且阅读/分享仍未知。只做结构、哈希及若干洁稿标记检查，输出匿名计数，不打印私有原文或路径；不是语义审核或评分器。
- 安装副本只含公开 Markdown，`.cursor/` 继续忽略；真实素材和结果不提交。

## 本轮保持不变的边界

独立 CLI 默认仍是离线摘录模板，模型适配器没有自动加载新 Skill；可移植指令只是未来接入参考。单次调用不等于多轮审稿。写作生成的 Markdown 尚未转换为带来源 Draft JSON，不能直接交给 `render`。

秀米账号内导入、编辑、保存、重开继续按用户决定延后；本轮不操作账号、不发布、不部署、不调用外部付费模型、不外发私有策划案，也不合入 `main`。
