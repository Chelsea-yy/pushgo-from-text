# 秀米可编辑导入验收（放宽目标版）

- 日期：2026-10-19。
- 目标：外部生成内容通过正常用户操作进入秀米，能够修改文字、单独替换图片，保存重开后修改仍存在。不要求秀米原生组件层级。
- 研究依据：`docs/research/xiumi-editable-import.md`；旧 `xiumi-native.md` 保留历史，不混用验收口径。
- 当前状态：**公开入口与帮助已实查；平台导入/编辑/保存重开尚未测试。主控最终验收。**

## 1. 安全前提

- 只用用户自己的账号，由用户正常登录；不读取登录态、不绕过登录/验证码/会员限制、不使用私有接口、不注入应用内部状态。
- 使用完全虚构的活动文案和获授权测试图片；禁止擅自将真实文档、私人图片送到秀米或第三方服务。
- 平台实测需用户明确批准创建和保存一篇虚构测试稿。未获授权只能查看公开入口，不点击保存/发布/同步，不购买权益。
- 不为实验要求用户付费。会员路线仅在用户自有账号已有适用权益且愿意测试时进行。

## 3. 样例要求

主控提供统一样例与记录标识：

- 1 个标题，2 段中文正文；正文含唯一标记 `XIUMI-EDIT-001`。
- 1 个简单信息卡片（虚构时间、地点和报名说明），1 个三项列表。
- 2 张分离的 `<img>` 测试图 A/C，另备替换图 B；不得把正文合成为一张图。
- 图片来源、授权、URL 是否稳定明确记录；测试图不使用真实个人信息或需要登录的 URL。
- HTML 正文尽量仅内联样式，标注可接受的样式降级；参考输出和源文件保留在本地。

## 4. 最短用户测试路线

### R1：官方说明的富文本粘贴（优先，编辑能力未知）

1. 用户在 Chrome/Edge 稳定版登录自己的秀米，进入图文编辑页 <https://xiumi.us/studio/v5/paper>。
2. 插入一个正文模板，在“设置”取消“粘贴时清除格式”；确认“粘贴时导入图片”并记录勾选状态。
3. 本地工具点击“复制排版”，把 `text/html` 与 `text/plain` 通过系统剪贴板正常写入；点击秀米正文，Ctrl+V。也可选中浏览器渲染正文 Ctrl+C 后 Ctrl+V。不要粘贴 HTML 源码当正文。
4. 检查标题、段落、列表、卡片和两张图片是否出现，记录排版变化与缺失。
5. 直接将中间标记改为 `XIUMI-EDIT-002`；使用可见正常编辑操作把图 A 单独替换成图 B，保留图 C。可用普通编辑行为或秀米可见功能，但不允许重贴整篇作为“编辑成功”。
6. 经用户授权保存测试稿，退出该稿并再次打开，检查修改持久化且文字、图片可继续修改。

风险：官方帮助原文明确说保留格式粘贴后“不能使用秀米的工具条进行编辑了”。因此步骤 5 是必须实测的重点；保留格式但文字/图片不可编辑视为失败，不因放宽“原生组件”要求而豁免。

### R2：更多 → 导入HTML代码（仅已有适用 VIP）

1. 记录用户账号有适用权限，不记录账号密码、Cookie 或令牌。
2. 打开“更多 → 导入HTML代码”，正常粘贴同一 HTML 正文源码，点击导入。
3. 重复 R1 的检查、改字、单图替换、授权保存和重开。说明是否覆盖原内容，保持测试稿独立。
4. 未登录实查文本框提示“该功能对等级会员VIP开放”且禁用。遇权限不足就停止，登记“账号/会员阻塞”，不购买、不绕过。

### R3：更多 → 导入Word/Excel/Markdown（内容降级备选）

1. 用同一虚构文案生成真正 `.docx` 或 `.md`，用户通过“选择文件”正常上传。
2. 官方窗口明确 Word 格式会清除，先按“内容可编辑”验证，不承诺原排版。
3. 检查文字与图片是否导入，再重复改字、替换图、保存和重开。
4. 记录需要手工补的步骤和耗时。若需要逐块重建正文/逐张重插图片，交主控判断体验是否可接受，不自动标注通过。
5. Excel 并非本项目首选；官方窗口说只导入首个工作表，不推断多表或复杂布局支持。

“导入公众号文章”菜单已经观察到，但未核实输入框和流程。现阶段不以它作为任意外部网页采集路线，不为测试先在公众号发布文章。

## 5. 本地可先验证项目（不触及秀米稿件）

- [ ] HTML 没有脚本、远程样式、真实文档或凭据；标题/正文为文本节点，图片是独立节点。
- [ ] 内联样式和绝对 HTTPS 图片 URL 正确；断网/图片失败时有可理解的替代说明。
- [ ] 标准复制按钮在正常点击下提供 `text/html` 和 `text/plain`；本地可见内容与载荷一致。
- [ ] 浏览器权限被拒绝时有明确提示，允许用户自行选中复制；不自动改权限或内部状态。
- [ ] “复制排版”与“复制 HTML 源码”含义清楚区分；后者只供官方 HTML 导入窗口使用。
- [ ] 纯文本回退明确标注不会保留图片/排版。
- [ ] 图片需用户确认来源和外发权限；不擅自上传到图床。

## 7. 本轮结论

P0 已有直接浏览器证据：官网新建入口、三个导入菜单、HTML VIP 限制、Word 格式清除提示、粘贴设置、官方外部复制帮助及其工具条编辑限制。主控之后完成本地工具与浏览器部分验证，L1 状态见上表；X1/X2/X3 仍未测试。虚构样例可通过 `node --import tsx scripts/create_import_fixture.ts` 生成到 `.local/xiumi-editable-fixture`，含三张本地几何 PNG，未上传。本轮没有上传任何内容或保存远程稿件；下一步在得到用户登录和虚构稿保存授权后完成平台闭环验证。
