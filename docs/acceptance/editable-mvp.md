## 结论

**本地流程通过主控自测，平台兼容性仍待用户账号实测。** 当前交付可以本地读取材料、整理有出处的草稿、选择三套主题、重排并导出富文本和可编辑 Word。离线模式是摘录模板，不冒充 AI 润色；模型适配器仅通过模拟接口验收。此结论不能用于宣称已经支持秀米或微信导入。

## 独立复核与返工

主控没有直接把并行交付记为通过：

- 回读方案比较证据并复跑解析、哈希及锚点检查。
- 发现公开脚本硬编码真实姓名后要求移至私有词库，修复后复跑隐私检查。
- 独立审查发现模型无引用正文仍可接受、数字子串误匹配、历史“相约”日期误提取、外部工作目录可绕过项目材料输出保护，均已修复并加入回归测试。
- 日期/时间自动提取收紧为显式字段；组合活动时间字段可派生其中的日期。自由叙述、历史和流程不能作为无条件回退。宁可提示未提取，也不选一个看似合理的值。

## 实际能力限制

1. 真实材料都可提取不等于关键字段全部自动识别；复杂标题、分行、多列和拟邀状态仍需人工确认。离线长方案会保留较多原文，不是直接可发布成稿。
2. 补充信息当前需加入有依据的本地材料再运行。没有自动联网补充、外部事实核验或图片下载。
3. `preview.html` 修改只存在页面内，不会回写草稿。长期修改应编辑 JSON 并 render 到新目录。
4. Word 保留可编辑文字和列表，图片为占位。秀米官方提示 Word 格式会清除，不承诺主题排版保留。
5. 用户手动加入的网络图片可能由浏览器请求，不能视为纯离线预览。敏感图片用本地素材并在平台自行上传。
6. 文件大小/字符限制不是恶意文档的进程级隔离；当前仅面向可信的本地材料，尚不可作为匿名上传服务。
7. 没有网页部署、小程序、自动发文或已确认开源许可证。

## 用户可验收的本地入口

运行 `npm run pushgo -- draft --input "examples/campus-reading.md" --out ".local/你的新目录" --theme campus`，先检查 `review.md`，再用浏览器打开输出目录的 `preview.html`。

需要统一的平台测试样例时运行 `node --import tsx scripts/create_import_fixture.ts`。固定输出 `.local/xiumi-editable-fixture`，已存在时会拒绝覆盖；含虚构文章和本地生成的三张几何色卡，不含真实材料。图甲/丙需人工上传，图乙用于单独替换；HTML 使用本地 assets 路径，Word 使用图片占位，不假定图片自动导入。

## 尚需用户参与

用户在自己的秀米账号正常登录，并明确授权只创建/保存一篇虚构测试稿（不发布、不同步、不购买），随后完成 `xiumi-editable.md` 中的编辑和持久性验证。普通账号先试富文本或 Word/Markdown；只有用户已拥有适用 VIP 权益才试 HTML 代码导入。此项完成前，全项目不能记为最终验收通过。
