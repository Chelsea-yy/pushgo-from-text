## 可复现命令

```powershell
uvx ruff==0.14.0 check scripts tests
uv run --with excel-mcp-server==2.2.1 python -m unittest discover -s tests -v
uv run --with excel-mcp-server==2.2.1 python scripts/verify_excel_mcp.py --workbook "你的本地表格.xlsx"
```

前两项只需虚构数据；第三项报告含真实内容，保存在 `.local/`，禁止提交。输入必须位于项目根目录或其子目录。首次下载依赖需要网络。
