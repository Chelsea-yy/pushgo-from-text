# 私有方案与公开成稿的匿名比较

## 范围与方法

在用户允许的内部读取范围内，本地解析5份材料：3份PDF，共16页；2份文字处理文档，共129个正文段落，包含空段。利用已有工作簿验收记录确认5条材料配对，并与已有的3份预告正文和1份回顾正文逐项比较。另2份材料缺少本次指定范围内的正文证据，因此只记录来源内部问题，不推断发布差异。

原材料读取前后逐一计算SHA-256摘要，5份均未改变；本地报告保留持久摘要基准、具体配对和页码或段落位置。本页仅记录匿名方法和结论，不披露原文件名、人物、原文、文章地址或活动精确日期。

解析仅在本地进行。隔离安装解析依赖，不上传材料，不执行文档中的宏、指令或链接，不调用外部文字识别服务。

分析脚本支持只提取使用者自己的材料：工作簿索引和正文快照是可选证据，缺失时记为未知并输出缺证据清单，仍可完成提取。未知校验项使用空值，不伪装成验证通过；已有证据中的真实不一致仍会使相应校验失败。敏感词库只保留在本地私有比较报告中，公开脚本不硬编码真实人物或材料名称。

## 匿名发现

| 案例 | 保留的信息 | 改写、冲突或证据缺口 |
| --- | --- | --- |
| 甲：方案、预告、回顾齐全 | 活动日期、总时段、七段预告流程基本保留 | 方案详细地址在预告中改为审核后通知；组织角色有变化或提取歧义；计划与回顾的主讲人不同；项目名单从预告九项变为回顾八项，方案内部两份名单也不一致。 |
| 乙：文字稿与预告 | 活动日期、时段、通知场地、报名通知机制及五项亮点保留 | 文稿列拟邀嘉宾，但成稿文字仅见相应标题，可能转为图片，不能断言删除；成稿新增组织名单、招募及致谢，需要独立来源。 |
| 丙：方案与预告 | 活动日期、总时段、四个主办单位、目标读者及大多数流程保留 | 一段圆桌开始时间相差十分钟；两处嘉宾职务表述变化；成稿仅展示部分嘉宾，另有履历和演讲题目新增；计划容量没有在文字成稿中出现。 |
| 丁、戊：只有来源材料 | 已提取信息和定位，保留拟邀、待定、报名截止等限定 | 存在组织表述不一致、审稿字段空白及演讲时长冲突；缺少配对正文，无法判断发布版本如何处理。 |

这些发现说明，方案到成稿包含对外披露调整、篇幅压缩、确认状态变化及事实更新，不能只做文本相似度比较。详细地址变为通知制，并不意味着应自动补齐；部分名单未见于文字，并不等于取消邀请。

## 对文稿生成和审核的要求

1. **事前与事后分开。** 计划、公开预告、会后报道分别保留来源与阶段。实际到场、现场反响、项目最终数量、融资意向等回顾断言，只用于回顾；不得写回预告。融资意向也不能改为融资完成。
2. **关键冲突交由人工确认。** 日期、流程时刻、场地披露范围、组织角色、职衔和名单不一致时并列显示证据，不自动任选一版，也不拼成兼任或确认出席。
3. **新增与缺失分别记录。** 成稿新增履历、题目或合作方需要另记来源；空字段和待确认内容保持显式状态，不能为了完整而补造。
4. **图片证据保持边界。** 纯文字快照未包含的嘉宾、二维码或图中信息统一标为未观察，而不是删除或不存在。PDF多列表格读序异常时，先核对原页再作名单结论。

用户当前目标是最终能够导入秀米并继续编辑。材料分析为文稿事实提供依据，不要求特定原生组件，也不替代编辑器导入与可编辑性验收。本次没有测试或宣称平台导入成功。

## 检查结果与限制

- 5份原材料读取前后摘要一致，并在对照完成后再次复核。
- 9项合成解析检查通过，覆盖段落和表格定位、无文字PDF页的诚实标记、不做外部文字识别、摘要保护、文件名规范化，以及4种缺少可选证据的独立提取场景。
- 对23条内部发现检查了来源位置，并验证21个成稿文字锚点存在。此检查证明可追溯性，不代替人工判断语义是否成立。
- 3份PDF的16页均产生文字；这不证明图片、混合扫描内容或所有版面信息已提取。遇到无文字页时程序会明确标记，保留本地人工复核要求。
- 文字处理文档的位置为段落序号而非排版页码；文本框、修订内容、图片、二维码目标以及页面视觉效果不在本次已验证范围。
- 内部完整证据保留在本地私有报告目录，包含实际配对、摘要和定位；本页不复制该私有内容。主控已独立复跑9项合成检查、23条定位与21个正文锚点检查，并抽查原文中的限定、组织与时间信息。此结论仅验收材料分析的可追溯性，不代表每项事实已获组织方确认。
