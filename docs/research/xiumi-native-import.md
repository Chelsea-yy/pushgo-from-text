## 1. 原生导入的判定边界

目标是将外部已生成的结构和内容写入秀米，再能在秀米内按原生模块选择、编辑、增删、调整顺序及保存重开。仅在浏览器里看到排版、可编辑普通文字、拿到图文 HTML，均不足以证明原生组件结构成立。

本项目不接受 HTML 粘贴、整篇图片、仅嵌入外部页面，或先打开秀米再由人逐块重建内容作为替代。也不采用逆向、猜测私有协议、抓取登录态、修改编辑器内部数据、浏览器脚本注入或自动化绕过限制。

## 3. 未证实与待官方确认

以下事项在本次两页公开证据中均未获得足够支持，保持“未证实”，不得作为实现前提：

2. 若存在，具体入口、接口或文件格式、公开说明、适用账号及应用类型、审核授权条件、配额、费用、测试环境和人工确认要求。

4. 写入后能否保持模块层级和独立选择、编辑、复制、移动、删除、图片替换，以及保存后重开仍可编辑。

**授权应分别确认：**同步应用的个人申请资格、代码／SDK 的开源分发许可、平台原生写入权限、模板／图片素材许可属于不同事项。任何一项获准，都不能代替其他项或证明原生导入已经可用。本次没有对任何许可作肯定认定。
