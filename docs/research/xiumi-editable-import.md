# 秀米可继续编辑导入：公开入口实查与实现决策

- 检查日期：2026-10-19，约 21:19–21:28（UTC+8）。
- 新目标：外部生成的内容能通过正常用户操作进入秀米，并继续修改文字、替换图片、保存及重开；不再要求成为秀米官方原生组件。
- 当前结论：**官方界面确有反向导入入口，值得实施最小样例；真实导入、文字编辑、图片替换和保存重开尚未通过验收。** 优先验证普通富文本粘贴；用户已有合资格 VIP 时可并行验证官方 HTML 代码导入。Word/Markdown 是降级备选，不能承诺保留排版。
- 本轮已实际使用浏览器访问官网、未登录编辑器和官方帮助，不是仅凭搜索结果推测。未登录任何账号，未填入正文、上传文件、创建远程稿件、保存、发布、付费或安装插件。仅访问空白编辑页和查看菜单/对话框。未使用私有协议、登录态、内部应用对象或状态修改。
- 历史说明：`docs/research/xiumi-native-import.md` 保留原约束研究，不改写其历史结论。本文件按放宽后的目标独立判断。

## 2. 实现路线建议：先做可交付内容，再验证平台

### 首选：内联样式 HTML + 正常复制粘贴 + 人工引导

1. 工具生成单独正文 HTML（非完整网页也可）和本地/本机预览；同一内容提供“复制排版”和“下载 HTML”。
2. 通过正常用户点击写入系统剪贴板，同时提供 `text/html` 与 `text/plain`；粘贴的是渲染后富文本，不是让用户把 `<section>` 源码当文字粘进正文。
3. 用户自有账号中按 E2 插入正文模板，取消“粘贴时清除格式”，按需保留“粘贴时导入图片”，点击正文后按 Ctrl+V。
4. 立即测试修改中间一句、替换一张图片，再经用户授权保存重开。
5. 此路线官方说明有支持也有编辑限制，**目前只是优先实验，不是实现完成承诺**。若图片不能替换或文字不能改，切换下一条，而非宣称可以。

### 用户已有合资格 VIP：直接走官方“导入HTML代码”

- 同一个 HTML 正文可直接粘入“更多 → 导入HTML代码”，绕过剪贴板保真不稳定点，但不绕过账号或会员检查。
- 开发无需接入私有接口；只需要导出正文和清晰步骤。需要用户自行合法登录且已有相应权益；不替用户购买、开通、提交申请。
- HTML 导入是否可编辑及保真仍必须实际验收，菜单存在不是完成证据。

### 降级：DOCX/Markdown 内容导入

- 平台明确支持 `.docx/.md` 文件入口，值得用同一虚构文案验证。
- Word 格式官方明确会清除；适合保留可编辑正文内容，不适合承诺保留原设计。
- 若 Markdown/Word 导入文字后，需要用户逐块重排并逐张重插，记录人工成本，让主控判断是否符合“最终内容可编辑”的可接受体验；不得暗中把大量重建包装成自动导入。
- 不应优先开发“HTML 改扩展名伪装 Word”；文件能够在 Word 中打开不是秀米 `.docx` 导入证据。

## 3. HTML/图片/剪贴板最小兼容约定（建议，非秀米官方承诺）

- 使用真实文本节点和独立 `<img>`；标题、段落、列表和简单单列卡片用 `section/p/span/strong/ul/li` 等常见标签；避免整篇截图、canvas、嵌入 iframe、脚本、表单和交互控件。
- 视觉关键属性以内联 `style` 写入：字号、行高、文字色、背景色、间距、边框、文字对齐；不依赖外部样式表、Tailwind 类、伪元素、网页自定义字体或 JavaScript。初版避开复杂 flex/grid、绝对定位、嵌套多列和背景图片承载正文。
- 图片采用用户有使用权的稳定 HTTPS 绝对 URL；不带登录 Cookie、临时令牌、个人信息或会过期的短期签名，不用 `localhost/file:/blob:`。`data:` 图片是否被秀米支持未知，不当默认通路。
- 图片用正常 `src` 而非仅 `data-src` 懒加载；建议 `display:block;max-width:100%;height:auto;`，有说明性 alt。图片转存可能需图库空间/账号权限；能在本地显示不代表秀米服务器能取到，也不代表重开仍能显示。
- 用户若不允许图片外发，用其自有授权图片和人工图库上传/替换路径；不要为研究把真实文档或图片送第三方图床。测试图用主控提供或另获授权的虚构图，远程取图也应记录来源。
- 复制按钮在用户点击事件中用标准 Clipboard API 写入 `ClipboardItem({'text/html': ..., 'text/plain': ...})`；需 HTTPS 或浏览器认可的本机安全上下文及正常权限。遇权限失败提供明确提示和选中预览手动 Ctrl+C；不自动提升浏览器权限、不修改内部状态。
- 同时提供纯文本回退，但界面应清楚说明“纯文本不保留排版/图片”，不能把复制成功提示等同秀米导入成功。对 HTML 源码展示提供独立“复制 HTML 源码”按钮，仅用于 VIP 对话框或人工诊断。

## 4. 最短真实复现路径及当前停止点

**零账号可复查（本轮已完成）**：打开官网 → “新建一个图文” → “更多” → 分别查看三个导入入口；HTML 查看 VIP 禁用提示；Word 查看支持格式和清除格式提示；关闭弹窗 → “设置”核对两项粘贴选项；帮助 → 帮助目录 → 搜索“如何复制其它编辑器的内容到秀米？”。

**用户后续最小测试（本轮未做）**：

1. 主控给出完全虚构的 1 个标题、2 段正文、1 个简单信息卡片、2 张测试图片，预留唯一文字 `XIUMI-EDIT-001`；准备替换图 B。
2. 用户自行登录自己的秀米账号；明确授权仅创建/保存这一篇虚构测试稿，不发布、不同步、不付费。
3. 首先按官方 E2 粘贴，修改标记文字为 `XIUMI-EDIT-002`，单独替换图片 A 为 B，确认另一图片与正文仍存在。
4. 用户允许后点击保存，退出该稿再打开；核对修改和替换持久化。仅本地预览/刚粘贴的画面不足以通过。
5. 不通过则记录操作/截图和失败类别：无富文本、样式清洗、文字不可改、图片不可替换、图片失效、保存/账号/会员门槛。若已有 VIP，再用相同样例验证 HTML 导入；否则用 `.docx/.md` 验证降级内容路线。

本轮停止在入口与帮助验证，不擅自继续到真实稿件或上传。保存/重开必然涉及用户账户中远程稿件，需用户明确授权。完整验收表见 `docs/acceptance/xiumi-editable.md`。

## 5. 决策结论与证据等级

| 层级 | 当前状态 | 可对外表述 |
| --- | --- | --- |
| 官方入口/公开操作存在 | 已实查 | 秀米提供外部粘贴说明、Word/Excel/Markdown 与会员 HTML 导入入口 |
| 本地 HTML/剪贴板能力 | 主控已实现并部分实测，详见 editable-mvp.md | 本地编辑与复制拒绝后的回退通过；真实剪贴板写入成功仍待验证，不记为秀米通过 |
| 秀米真实导入并修改文字/图片 | 未测试 | 需用户自有账号与虚构样例；富文本路线有工具条限制风险 |
| 保存重开持久可编辑 | 未测试 | 需用户授权创建/保存虚构测试稿；主控最后验收 |

**足以决定的实现方向**：可先投入“语义正文 + 内联 HTML + 标准富文本复制/HTML 下载 + 清晰手动步骤”的小规模实现，不必继续等待未知原生写入接口；同时保持平台能力状态为“待用户实测”。目前证据不足以承诺“免费保排版且图片可编辑”或“一键直接写入秀米”。
