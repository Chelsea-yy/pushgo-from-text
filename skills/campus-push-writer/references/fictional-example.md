# 虚构示范：从组织方目的到读者文稿

本页全部由项目独立构造，不对应真实活动或参考文章。用于说明转换方法，不代表可报名，不使用真实嘉宾、单位、地点或活动日期。

## 虚构材料

- 活动名称：星河跨学科项目交流午后。
- 目标读者：正在尝试跨学科小项目的校内学生。
- 目的：促进不同专业学生交流项目组织经验。
- 内容：两段学生项目经验分享，小组互问；话题为如何把研究问题拆成任务、怎样沟通不同专业的分工。
- 嘉宾：拟邀请高年级学生，名单未定。
- 时间：暂定下学期某个周三15:00—16:30，日期未定。
- 内部地点：某教学楼会议室，是否公开未确认。
- 报名方式：尚未确定；没有二维码、截止、费用或证书信息。

## 模块选择

问题导语 → 活动定位 → 具体参与内容 → 适合谁 → 轻量邀请。暂不写可执行报名模块，也不列拟邀姓名/详细地点。原材料没有具体日期，不能硬补基本信息卡使它看起来完整。

## 标题备选

1. 想做跨学科小项目，先从哪些问题聊起？（采用，内容能回应）
2. 星河项目交流午后：从任务拆分聊到团队沟通（活动与具体内容角度）
3. 一个研究问题，如何成为可以一起推进的小项目？（问题角度）

## 读者稿

### 想做跨学科小项目，先从哪些问题聊起？

有了一个研究问题，下一步怎样拆成可以尝试的任务？不同专业的同学一起合作时，又该怎样把分工说清楚？

星河跨学科项目交流午后，想把讨论放在这些具体问题上。活动计划通过学生项目经验分享和小组互问，让正在尝试跨学科项目的同学交换思路。

**先听项目是怎样推进的。** 两段经验分享将围绕任务拆分与跨专业沟通展开。与其只看最终成果，不如一起讨论过程中需要作出的选择。

**再把自己的问题带进交流。** 小组互问环节让大家围绕各自关心的问题继续讨论。交流前，可以先整理几个问题：目前最想推进的是什么，又卡在哪一步？

如果你正在寻找项目合作的表达方式，或希望听听其他专业同学的理解，欢迎关注这次交流午后。

## 审核记录示意（非独立评审）

- “两段分享”“任务拆分”“沟通分工”“小组互问”均来自虚构材料；没有变成“现场解决所有项目问题”。
- 邀请语是表达建议，不保证匹配到队友或获得持续指导。
- 时间只有暂定时段和不确定学期日期，详细地点公开范围未确认；洁稿暂不写。
- 嘉宾是拟邀，不写“学长学姐确认到场”，也不捏造姓名。
- 没有报名资产，不写“扫描下方二维码”；最终发布仍被日期、地点与报名条件阻塞。
- 原稿的“促进交流”被具体化为任务拆分、沟通和互问；企业规模、宏观背景或空泛“干货满满”都没有必要。

该示范只展示写法。真实案例应保留具体来源位置、变更和独立评审，而不是把此页的自我解释当作独立验收。
