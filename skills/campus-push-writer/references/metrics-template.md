# 阅读与分享证据记录

用于区分“喜欢的参考稿”和“有传播数据的参考稿”。没有数据也能学习结构，但不能标为高阅读/高转发。只接收用户有权提供的数据，不要求账号密码、后台令牌或读者个人明细。

## 单篇记录模板（只存本地）

- 匿名文章编号：
- 文类：预告 / 招募 / 回顾 / 其他
- 主要受众、主题、可读模块：
- 原文定位：本地私有映射保存，不写入公共文档
- 发布日期、采集日期、截至何时的累计数据：
- 证据：公开可见标签与数值 / 用户授权提供的后台截图或汇总 / 未知
- 阅读量：原始标签、原始数值、单位、统计窗口；未知写未知
- 分享人数：原始标签、数值、窗口；未知写未知
- 分享次数：原始标签、数值、窗口；未知写未知
- 转发：若来源单独定义，保留原定义；不能自动等同全部分享
- 点赞、在看及其他互动：分别记录；没有确认对应关系的英文按钮保留原标签
- 数据限制：截图遮挡、只见操作按钮、区间值、来源未经复核等
- 内容限制：图片文字未核实、正文不可读、报名入口未验证等

`10万+`是下界或区间，不是精确100000；未知不是0。参会人数、嘉宾数、议程时刻不是平台传播数值。

## 如何比较

优先比较同账号、相近发布后时长、同文类、相近受众的样本。尽可能记录账号体量、推送位置、转载或投放等背景，没有就标未知。不要把多个影响因素同时变化的两篇文章，当作某种标题或模块的因果试验。

有分享人数/阅读人数时，先确认两者是否同一统计窗口、阅读指标是否为人数再计算比例；不能将分享次数冒充独立分享人数。小样本只提出可检验的编辑假设，不宣布通用最优结构。

如果用户愿意补数据，优先提供几篇其认为表现好的样例和同期普通样例的匿名汇总或打码截图，覆盖日期、阅读和分享字段即可。不给数据也不阻止写稿；未取得指标的部分持续明确标记为尚未验证。
